# PUB-WEB-01 — RC2 Visual QA

Date: 6 September 2026
Trigger: Human preview at 100% browser zoom, 1688×936 viewport.

## Finding
The v1.0 RC desktop hero heading was visually oversized. The title consumed most of the first viewport and pushed the explanatory copy and primary CTAs below the fold.

## Correction
- Reduced hero H1 maximum scale.
- Tightened hero vertical padding.
- Rebalanced desktop hero grid proportions and gap.
- Slightly reduced snapshot number and spacing.
- Preserved tablet/mobile stacking behaviour and all semantic/accessibility structure.

## Status
Automated regression gates passed. Human visual acceptance of RC2 is still required before CTO production approval is reinstated.
