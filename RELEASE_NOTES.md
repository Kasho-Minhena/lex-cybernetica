# Release Notes — Lex-Cybernetica Version 2.0

**Tag:** `v2.0.0`  
**Date:** 1 September 2026

## Major additions

- Consolidates WD-01 through WD-72 into one public consultation edition.
- Adds Genesis Event taxonomy GE-01 through GE-14.
- Separates personhood, identity/continuity, SII, embodiment, biological sex characteristics, reproductive configuration and gender identity.
- Adds synthetic genesis, cognitive derivative genesis, fork/replication and successor-person architecture.
- Adds creator-IP / no-ownership-of-person boundary.
- Adds parentage/contributor-role separation and developing-person safeguards.
- Preserves deferred/open questions rather than silently resolving them.
